    Can an attacker rebuild a patient from an update?

    A gradient-inversion attack takes one hospital's model update and tries to reconstruct the vitals that produced it. Without privacy noise it works. With FedGuard's noise it fails.

  "methods": [ {"name": "Local-only", "auroc": 0.72, "auprc": 0.07}, ... ],
  "prevalence": 0.02,
  "privacy": { "eps": [1, 2, 3, 5, 8], "uniform": [...], "adaptive": [...], "no_dp": 0.82 },
  "alerts": {
    "threshold_only": {"false_per_100h": 4.1, "sensitivity": 0.80},
    "fedguard":       {"false_per_100h": 3.2, "sensitivity": 0.79}
  },
  "patients": [
    { "name": "Test patient 1021", "onset_hour": 34,        // null if never septic
      "hr": [...], "map": [...], "resp": [...], "temp": [...], "spo2": [...],
      "risk_mean": [...], "risk_std": [...],            // one value per hour
      "attr_features": ["HR","MAP", ...],               // optional explanation
      "attr": [[...per feature...], ...]                 // one row per hour
    }
  ]
}

    Every key is optional. Whatever you include replaces the demo numbers.
